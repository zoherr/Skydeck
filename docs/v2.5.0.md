# Skydeck v2.5.0 — Productivity & Power Tools

> **Skydeck** — Your servers from above. A fast, secure VPS workstation combining Go, Electron, React, and Monaco.

---

## 🎯 Executive Summary & Objectives

The primary objective of **Skydeck v2.5.0** is to eliminate context switching. Developers and system administrators should no longer need to switch between an SSH terminal (like iTerm, Termius, or PuTTY), a separate FTP client (like FileZilla or WinSCP), and an external text editor.

By introducing an **integrated PTY terminal**, **dual-pane explorer**, **content search**, **rich media preview**, and a **dedicated background transfer manager**, Skydeck transforms from a file manager into a high-productivity developer command center.

---

## 🏗️ Architecture Expansion

```
[ Electron Shell (React + Tailwind + xterm.js + Monaco) ]
     ↕ IPC (Strict Context Isolation)
[ Preload Bridge ]
     ↕ REST + WebSockets (127.0.0.1:48921 with crypto token)
[ Go Backend (Gin Engine) ]
  ├── session/       → SSH Connection Pooling & Session Lifecycle
  ├── terminal/      → PTY / Interactive Terminal WebSocket Stream
  ├── transfer/      → Background Concurrency Queue (Upload/Download/Resume)
  ├── search/        → Fast Go Regex & In-File Grep Engine
  ├── archive/       → Tar, Gzip, and Zip Archival Streaming
  └── handlers/      → REST Endpoints (Files, Chmod, Read, Write, Stat)
     ↕ Multiplexed SSH2 / SFTP Connections
[ Remote VPS Server ]
```

## 🚀 Core Features & Specifications

### 1. 🖥️ Integrated SSH Terminal
- **Terminal Engine**: Embedded `xterm.js` with canvas/webgl renderer, ANSI 256-color & 24-bit TrueColor support.
- **PTY Backend**: Go backend allocates pseudo-terminals (`crypto/ssh` session PTY) streamed bidirectionally via WebSockets.
- **Multiple Tabs**: Spawn multiple concurrent shell tabs per server or across different connected servers.
- **Shell Compatibility**: Auto-detects and supports Bash, Zsh, Fish, and Sh.
- **Path Synchronization**: Option to synchronize the terminal's working directory (`cd`) with the visual file explorer's current directory.
- **Terminal Features**:
  - Full copy/paste support (Ctrl+Shift+C / Ctrl+Shift+V or standard shortcut).
  - Terminal resize event negotiation (`SIGWINCH` propagation).
  - Search within terminal buffer.
  - Persistent command history log.

### 2. 🗂️ Dual-Pane File Manager
- **Layout Options**:
  - *Single Pane*: Standard Skydeck v2 layout.
  - *Dual Pane*: Side-by-side explorer (Local Client ↔ Remote VPS, or Remote VPS A ↔ Remote VPS B).
- **Direct Transfers**: Drag and drop files directly between left and right panels.
- **Remote-to-Remote**: Fast server-side copy/move operations between different directories without downloading to local disk.
- **Multi-Selection**: Selection using Shift+Click (range) and Ctrl+Click (additive).
- **Power Shortcuts**:
  - <kbd>F5</kbd> — Copy selected items to opposite pane
  - <kbd>F6</kbd> — Move / Rename selected items
  - <kbd>F7</kbd> — Create directory
  - <kbd>F8</kbd> / <kbd>Delete</kbd> — Delete with confirmation
  - <kbd>Tab</kbd> — Switch focus between panes

### 3. 🔍 Advanced File Search
- **Filename Search**: Instant client-side and server-side fuzzy matching with wildcard (`*.conf`, `app.*.js`) and regex support.
- **Content Grep Search**: Search for strings or regex patterns *inside* text and code files on the remote server using optimized Go routines.
- **Advanced Filtering**:
  - Filter by size (e.g. `> 100MB`, `< 5KB`).
  - Filter by modification date (e.g. past 24 hours, past 7 days).
  - Filter by file extension and permissions.
- **Direct Navigation**: Clicking any search result instantly jumps to the containing directory and highlights the target file.

### 4. 👁️ Rich File Preview System
- **Image Preview**: Full-screen modal with pan, smooth zoom (25% to 400%), natural dimension stats, and transparent checkerboard background (`.png`, `.jpg`, `.jpeg`, `.svg`, `.webp`, `.ico`, `.gif`).
- **PDF Viewer**: Embedded PDF renderer for viewing documents, invoices, and manuals on remote storage.
- **Audio & Video Player**: Stream media files directly from the server with playback controls (`.mp4`, `.webm`, `.mp3`, `.wav`, `.ogg`).
- **Interactive JSON Viewer**: Collapsible syntax tree with search, node copy, and format validation.
- **Markdown Live Preview**: Split-pane or toggle preview rendering GitHub Flavored Markdown, checklists, KaTeX math formulas, and code highlighting.
- **Archive Inspection**: Inspect contents of `.zip`, `.tar.gz`, `.tar.bz2`, and `.tar.xz` archives without downloading or extracting.

### 5. ⚡ Advanced Transfer Manager
- **Concurrency & Queue**: Multi-threaded transfer queue supporting configurable parallel streams (default: 3 concurrent transfers).
- **Control**: Pause, resume, cancel, or re-order queued uploads and downloads.
- **Resumable Transfers**: Uses SFTP byte-range offsets (`seek`) to resume interrupted large file transfers.
- **Live Transfer HUD**:
  - Floating or docked transfer widget showing speed (`MB/s`), progress percentage, bytes transferred, and accurate ETA.
- **Transfer History**: Log of completed, failed, and canceled transfers with one-click retry.

### 6. 📑 Multi-Tab Workspace
- **Multi-File Monaco Tabs**: Open multiple text/code files simultaneously with tab bar navigation, close all, close others, and pinned tabs.
- **Side-by-Side Diff Editor**: Compare two configuration files or revisions with Monaco's visual side-by-side diff viewer.
- **Workspace State Persistence**: Remembers open tabs, active connection, and layout across app restarts.
- **Quick Bookmarks**: Pin frequently used directories (e.g. `/var/www/html`, `/etc/nginx`, `/var/log`) to the sidebar.

## 🔧 Technical Upgrades Under the Hood

1. **SSH Connection Pooling**:
   - Separate multiplexed channels for terminal, SFTP file transfer, and background health checks so large transfers never freeze terminal sessions.
2. **Chunked Memory Buffers**:
   - Stream large files in 64 KB / 128 KB chunks directly through pipes, preventing high RAM consumption in Go or Electron.
3. **Structured Logging**:
   - Rotating JSON / human-readable server logs with log levels (`DEBUG`, `INFO`, `WARN`, `ERROR`).

# Skydeck v2.0.0 — The Complete VPS File Manager

> **Skydeck** — Your servers from above. A fast, secure cross-platform VPS file manager built with an embedded Go SSH/SFTP backend, Electron, React, and Monaco Editor.

---

### 🚀 Highlights in v2.0.0

- **Integrated Go Backend**: Embedded `127.0.0.1:48921` Gin server running `golang.org/x/crypto/ssh` and `pkg/sftp` with auto-reconnect and 30-minute idle session reaper.
- **Strict Token Authentication**: Every internal API request is guarded with a cryptographically generated `X-Skydeck-Token`.
- **App-Level Password Protection**: Master password hashed with bcrypt (cost 12), with enforced 30-second lockout after 5 incorrect attempts.
- **AES-256-GCM Encrypted Profiles**: Server connection profiles encrypted at rest using keys derived via PBKDF2-HMAC-SHA256 (100,000 iterations). Passwords are never saved to disk.
- **Visual File Browser**: Navigate remote folders, clickable breadcrumb bar, sorting, inline renaming, folder creation, and drag-and-drop file upload.
- **In-App Monaco Code Editor**: Syntax highlighting for 20+ file extensions, Ctrl+S save shortcut directly back to VPS, and unsaved changes indicator.
- **File Permissions (chmod) Editor**: Interactive 3×3 permission matrix (Owner, Group, Others) with octal notation support.
- **Windows Installer**: NSIS desktop setup with embedded backend binary.

# Skydeck v1.0.1 — Release Notes

> **Skydeck** — Your servers from above. A fast, secure VPS file manager built with Go + Electron.

---

## 📦 What is Skydeck?

Skydeck is a cross-platform desktop application that lets you connect to any VPS or remote server via SSH/SFTP and manage your files visually — no terminal required. Built for developers who want speed, security, and a clean UI.

---

## 🏗️ Architecture

```
[ Electron Frontend (React + Tailwind) ]
            ↕ REST API (localhost:48921)
[ Go Backend (Gin + paramiko) ]
            ↕ SSH / SFTP
[ Your VPS ]
```

| Layer | Technology |
|---|---|
| Desktop Shell | Electron |
| UI Framework | React + Tailwind CSS |
| Backend | Go (Gin HTTP server) |
| SSH/SFTP | golang.org/x/crypto/ssh + pkg/sftp |
| Build | electron-builder → .exe installer |

---

## ✅ V1.0.1 Features

### 🔐 Connection & Auth
- Connect to any VPS via SSH (port configurable, default 22)
- Auth via **password** or **SSH private key file**
- Save and load multiple VPS profiles locally
- Profiles stored in Electron's `userData` as JSON
- Connect / disconnect with status indicator

### 📁 File Browser
- Navigate remote folders by clicking
- Breadcrumb path bar with back navigation
- File list with: name, size, modified date
- File type icons (folder, image, code, text, archive, unknown)
- Refresh current directory

### 📄 File Operations
- **Upload** — send local files to current remote folder
- **Download** — pull remote files to local machine
- **Delete** — remove files or folders (with confirm dialog)
- **Rename** — rename files and folders inline
- **New Folder** — create directories on the remote server

### ✏️ In-App Text Editor
- Click any text/config file to open in editor
- Supported: `.txt` `.conf` `.yaml` `.yml` `.json` `.env` `.sh` `.md` `.ini` `.log`
- Save changes directly back to VPS
- File path shown in editor header

### 🖥️ UI / UX
- Dark theme — background `#0f1117`, surface `#1a1d27`
- Accent color: `#6366f1` (indigo)
- Font: Inter
- Left sidebar: saved profiles + connection info
- Toast notifications for all operations
- Loading spinners during file operations
- Error handling with clear messages

## 🔒 Security Notes (V1)
- SSH credentials never stored in plaintext (passwords not saved to profiles)
- Sessions held in-memory on Go backend only
- Backend only listens on `localhost` — not exposed to network
- Private key paths stored (not key contents)

---

## ⚠️ Known Limitations (V1 → fixed in V2)
- No drag and drop upload
- No terminal / shell emulator
- No file permissions editor
- No multi-tab support
- No file search
- No image/media preview
- No app-level password protection
- No automatic session reconnect

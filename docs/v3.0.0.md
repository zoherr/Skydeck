# Skydeck v3.0.0 — Complete VPS Management Platform

> **Skydeck** — Your servers from above. The all-in-one desktop control center for developers, devops, and server administrators.

---

## 🌐 Vision: Beyond File Management

**Skydeck v3.0.0** represents a quantum leap in product scope. Rather than being merely a remote file browser, Skydeck evolves into a **unified desktop operating system for your cloud servers**.

Managing a modern Linux VPS typically requires juggling five or more disconnected tools:
- PuTTY / Termius for shell access
- FileZilla / Cyberduck for SFTP
- Portainer or CLI for Docker
- DataGrip / DBeaver for database queries
- Grafana / Netdata / Datadog for hardware monitoring
- Webmin / Cockpit for server administration

**Skydeck v3.0.0 unites all of these workflows into a single, high-performance, dark-themed native desktop application.**

---

## 🏗️ Modular Architecture (v3.0)

To support this expansive feature set without bloat, the Go backend transitions to a clean, decoupled modular micro-kernel design:

```
[ Skydeck Desktop Client (Electron + React) ]
     ↕ Secure REST + Multiplexed WebSocket Event Bus (127.0.0.1:48921)
[ Skydeck Core Go Engine ]
  ├── core/
  │    ├── auth/          → Master Password & Token Validation
  │    ├── session/       → SSH Connection Pooling & Auto-Reconnect
  │    └── events/        → WebSocket Pub/Sub Event Hub
  └── modules/
       ├── sftp/          → File Management, Dual Pane, Streaming Transfers
       ├── terminal/      → xterm.js Multi-PTY Streamer
       ├── monitor/       → /proc & sysstat Hardware Telemetry
       ├── process/       → Linux Process Table & Signals
       ├── docker/        → Docker Engine API over SSH Tunnel / Unix Socket
       ├── systemd/       → Systemd D-Bus & Unit Management
       ├── database/      → Direct Drivers (MySQL, PostgreSQL, Redis)
       ├── deployment/    → Git Hooks, Build Scripts, Rollback Engine
       ├── backup/        → Restic / Tar Encrypted Backup Automation
       └── security/      → UFW Firewall, Auth Logs, Listening Ports
```

## 🖥️ Core Modules & Capabilities

### 1. 📊 Server Monitoring Dashboard
Real-time server telemetry collected efficiently from `/proc` and `sysinfo` without requiring third-party cloud agents:
- **Metrics**:
  - Live CPU utilization gauge + per-core breakdown.
  - RAM & Swap utilization (Active, Cached, Buffers, Free).
  - Disk storage utilization per mount point (`/`, `/home`, `/data`).
  - Network throughput graph (Upload/Download bandwidth in real time).
  - System load averages (1m, 5m, 15m) and system uptime.
- **Hardware & OS Summary**: OS distribution, Linux kernel version, CPU architecture, hostname, and private/public IP details.

---

### 2. ⚡ Process Manager
An interactive, graphical task manager for remote Linux processes:
- **Process List**: Table showing PID, User, CPU%, Memory%, Nice, State, and Command.
- **Sorting & Search**: Instant filtering by process name, command, or PID; sort by memory or CPU hogs.
- **Signal Control**: Terminate (`SIGTERM`), Force Kill (`SIGKILL`), or restart processes with a single click.
- **Process Tree**: View parent-child process hierarchy (e.g., Nginx master and worker processes).

---

### 3. 🐳 Docker Management (First-Class Citizen)
Direct communication with the remote Docker daemon via SSH tunneling to the Docker Unix socket (`/var/run/docker.sock`):
- **Container Control**:
  - View all containers with live status indicators (running, stopped, restarting, unhealthy).
  - One-click Start, Stop, Restart, Pause, and Delete.
  - Interactive terminal inside any container (`docker exec -it <container> /bin/sh`).
  - Real-time streamed container logs with follow and tail controls.
- **Image & Volume Management**:
  - Browse downloaded Docker images, inspect tags and sizes, and prune unused images.
  - List and inspect Docker volumes and storage bindings.
- **Docker Compose**:
  - Visual stack viewer for `docker-compose.yml` deployments.
  - One-click `compose up -d`, `down`, and `restart`.

---

### 4. ⚙️ Systemd Service Management
Full lifecycle control of system services:
- **Service Browser**: Search and filter all `systemd` units (Nginx, MySQL, Redis, Docker, SSH, custom daemons).
- **Control Actions**: Start, Stop, Restart, Reload, Enable (at boot), and Disable services.
- **Log Inspection**: Live streamed logs directly from `journalctl -u <service> -f`.
- **Configuration Quick-Edit**: Click to open unit files or related `/etc/` configurations in Monaco editor.

---

### 5. 🗄️ Database Management
Connect and explore databases hosted on your VPS through secure SSH port forwarding:
- **Supported Engines**: MySQL, MariaDB, PostgreSQL, SQLite, and Redis.
- **Database Explorer**: View databases, tables, views, indexes, and schema definitions.
- **SQL Query Runner**: Monaco-powered SQL editor with syntax autocomplete, execution timer, and formatted table results.
- **Redis GUI**: Inspect keys, key types (`string`, `hash`, `list`, `set`, `zset`), TTL, and execute raw Redis commands.
- **Export & Backup**: Export database dumps (`.sql`, `.csv`) directly to local machine or remote backup storage.

---

### 6. 🚀 Deployment & Application Manager
Deploy web applications and APIs directly from Skydeck:
- **Git Integration**: Clone, fetch, pull, and checkout branches directly on the VPS.
- **Build & Run**: Trigger custom build commands (`npm run build`, `go build`, `cargo build`, `python manage.py migrate`).
- **Environment Manager**: Secure visual `.env` variable editor with masked values and environment template sync.
- **Release History**: Track deployment timestamps, commit SHAs, author, and deployment logs with 1-click rollback.

---

### 7. 🛡️ Security Center & Auditing
Proactive security audits and threat visualization:
- **SSH Access Log**: Visual log of recent SSH logins (Accepted and Failed attempts) with IP geolocation and flag icons.
- **Brute-Force Alerts**: Highlight repeated failed login attempts from malicious IPs.
- **UFW Firewall Manager**:
  - View firewall status (`active` / `inactive`).
  - Allow or deny ports/protocols (`allow 443/tcp`, `deny 23`).
  - List and delete active firewall rules.
- **Port Inspector**: Real-time list of all listening ports, protocols (`TCP`/`UDP`), and the bound processes (`ss -tulpn`).
- **Linux User Manager**: Inspect users (`/etc/passwd`), active sessions, and sudo privileges.

---

### 8. 💾 Automated Backup & Disaster Recovery
- **Snapshot Backups**: Create point-in-time compressed backups of specified directories or full server configs.
- **Scheduled Automation**: Set cron-based recurring backups (daily, weekly) with retention policies (keep last N backups).
- **Encrypted Archives**: Client-side AES encryption for backup archives before uploading to offsite storage.
- **One-Click Restore**: Restore files or configurations from any previous backup archive.

---

### 9. 🧰 Advanced Server Utilities

| Tool | Capability |
|---|---|
| **Visual Cron Manager** | Create, edit, enable, and test Linux cron jobs with visual schedule builders (e.g. "Every Sunday at 3 AM"). |
| **System Log Hub** | Central viewer for `/var/log/syslog`, `/var/log/auth.log`, `/var/log/nginx/`, with live search and severity filtering. |
| **Network Diagnostic Tools** | Perform remote ping, traceroute, DNS lookup (`dig`), and curl HTTP tests from the server's perspective. |
| **Storage Analyzer** | Treemap / sunburst visual breakdown of storage usage to pinpoint runaway log files or cache bloat. |
